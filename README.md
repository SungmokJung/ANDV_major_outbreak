# Probability of a major ANDV outbreak within MSM sexual networks

Underlying code for Jung et al., "Introduction of Andes hantavirus into sexual networks as an adverse scenario: lessons from the 2022 global mpox outbreak"

## Note
The branching-process model was adapted from a previous study of mpox emergence. See the [original study](https://www.science.org/doi/10.1126/science.add4507) for a detailed description.
